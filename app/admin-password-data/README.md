# Common password rejection data

`common-passwords.txt.gz` is the unmodified data at
`django/contrib/auth/common-passwords.txt.gz` from Django 5.2.18, a public release of Django. Its SHA-256 is
`3c1baed62596de36860824eb3f436d5932d37ca8b06e59df78f5a44ec175afe4`,
matching the wheel's RECORD. The distribution has 19,640 distinct entries. Django credits Royce Williams for the
[original list](https://gist.github.com/roycewilliams/226886fd01572964e1431ac8afc999ce).

binary distributions. This is public validation data, not account material.
